# Waist Circumference and Body Weight

**Course:** University of California Riverside, STAT 107, Introduction to Statistical Computing with R  
**Student:** Harshini Hirpara  
**Due Date:** July 28, 2026  

## Project Overview

This study uses data from 507 active individuals to investigate the relationship between waist circumference and body weight. A linear regression model with an interaction term is used to determine whether this relationship differs between males and females.

## Repository Contents

- `Analysis.qmd`: Contains the written analysis, code, and results
- `analysis_functions.R`: Imports and prepares the dataset
- `data/body.dat.txt`: Contains the body dimensions dataset
